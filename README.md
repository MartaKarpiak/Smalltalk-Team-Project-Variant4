# Командне завдання з Smalltalk

## Варіант №4

Командний проєкт з дисципліни: "Об'єктно-орієнтована система Pharo"

## Завдання

Необхідно реалізувати систему для роботи з фруктовими деревами у Smalltalk.

### Основні класи

Створити базовий клас `Фруктове дерево`, який містить:
- назву виду дерева;
- вік;
- висоту;
- урожайність;
- вік початку плодоношення.

Для об'єктів класу необхідно реалізувати:
- збільшення віку дерева на один або декілька років;
- зміну висоти та урожайності з віком;
- введення та виведення об'єктів;
- оператори/методи порівняння;
- арифметичні операції;
- метод перевірки урожайності.

### Яблуня

Створити клас `Яблуня`, успадкований від фруктового дерева.

Особливості:
- плодоношення один раз на два роки;
- зберігає інформацію про колір плодів.

### Абрикос

Створити клас `Абрикос`, успадкований від фруктового дерева.

Особливості:
- зберігає інформацію про те, чи були заморозки під час цвітіння;
- у разі заморозків урожайність зменшується на 80%.

### Робота з колекцією

Створити колекцію з декількох яблунь та абрикосів і реалізувати:
- виведення всієї колекції;
- додавання нового дерева в режимі діалогу;
- пошук найстарішого дерева;
- пошук дерева з найнижчою урожайністю;
- перевірку, чи всі дерева досягли віку плодоношення;
- збільшення віку кожного дерева на один рік;
- збільшення віку кожного дерева на два роки;
- збереження колекції у файл;
- пошук трьох найурожайніших дерев;
- створення нової колекції дерев, висота яких не перевищує задане значення.

### Збереження даних

Продемонструвати:
- збереження створених об'єктів у файли різних форматів;
- завантаження об'єктів із файлів;
- збереження об'єктів у базу даних;
- завантаження об'єктів із бази даних.

Наявність реальної бази даних не є обов'язковою — її можна імітувати в пам'яті.

### Тестування

Функціональність класів перевірити за допомогою модульних тестів.

### Організація проєкту

- класи розмістити в окремому пакеті;
- приклади використання можна оформити методами додаткового класу;
- дані про екземпляри класів можна задавати у Playground, вводити з клавіатури або завантажувати з файлу.
